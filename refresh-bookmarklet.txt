ROLZO WATCHER — ONE-CLICK TOKEN REFRESH BOOKMARKLET (Render deployment)
=========================================================================

Target: https://rolzo-bot.onrender.com/update-creds
Secret: must match REFRESH_SECRET set in Render's Environment tab
        (currently: YKD0uC9Serwo0eZ80AxeyW43o8Lm2lYC — if you ever rotate
        this in Render, regenerate the bookmarklet with the new value too,
        they have to match or every refresh gets a 401).

Setup (once):
1. Show your browser's bookmarks bar (Ctrl+Shift+B in Chrome/Edge).
2. Right-click the bookmarks bar -> Add page / New bookmark.
3. Name it something like "Refresh Rolzo Token".
4. Paste the ENTIRE line below as the URL/location, save.

javascript:(function(){try{var raw=localStorage.getItem('RolzoCurrentUser');if(!raw){alert('Rolzo watcher: RolzoCurrentUser not found — are you logged in?');return;}var u=JSON.parse(raw);if(!u.authToken||!u.userId){alert('Rolzo watcher: authToken/userId missing from stored session.');return;}fetch('https://rolzo-bot.onrender.com/update-creds',{method:'POST',headers:{'Content-Type':'application/json','X-Refresh-Secret':'YKD0uC9Serwo0eZ80AxeyW43o8Lm2lYC'},body:JSON.stringify({authToken:u.authToken,userId:u.userId})}).then(function(r){return r.json().then(function(j){return{ok:r.ok,j:j};});}).then(function(res){if(res.ok)alert('Rolzo watcher: credentials refreshed'+(res.j&&res.j.resumed?' — watcher resumed!':' ✅'));else alert('Rolzo watcher rejected the update: '+(res.j&&res.j.error));}).catch(function(e){alert('Could not reach the watcher: '+e.message);});}catch(e){alert('Rolzo watcher bookmarklet error: '+e.message);}})();

How to use it:
- Whenever the watcher pauses on repeated auth failures (Discord will tell
  you), or any time you want to pre-emptively refresh: open
  business.rolzo.com in a tab where you're logged in, click the bookmark.
- Reads your session's own authToken/userId from that page's localStorage
  and sends only those two values, plus the shared secret, to the deployed
  watcher — no password, nothing else leaves your browser.
- Unlike the old local version, this now talks to your Render deployment
  over the internet, authenticated by REFRESH_SECRET — anyone without that
  secret gets a 401, even though the URL itself is public.

Discord commands (once Message Content Intent is enabled for the bot):
  !status   — is it running, live/dry-run, uptime, last activity, real log tail
  !stop     — pause polling/accepting (does not kill the process — it can
              still hear !start afterward)
  !start    — resume polling
